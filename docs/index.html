One DataFrame.
Every Angle.

Give Chartly a DataFrame, pick your fields, set your defaults, and explore your data from many perspectives in a single interactive chart. 

from chartly import Chart
import polars as pl

df = pl.read_csv("sales.csv")

chart = Chart(
    id="revenue",
    data=df,
    default_x="Region",
    default_y="Revenue",
    default_color="Product",
    default_graph_type="bar",
    colormaps={"Product": {"Widget": "#6366f1", "Gadget": "#22d3ee"}},
)
chart.update_figure()
chart.show_figure()

Basic Usage

Chartly is designed for Streamlit apps. Import Chart, hand it your DataFrame and column preferences, and you get a fully interactive chart widget with dropdowns for graph type, axes, color, facets, date grouping, and more.

With Filters

from chartly import Chart, Filter, filter_data

# Build interactive filters
flt = Filter(id="sidebar")
flt.multiselect("Region", options=["North", "South", "East", "West"])
flt.selectbox("Year", options=[2023, 2024, 2025], filter_type="gte")

# Apply filters to data
df_filtered = filter_data(df, flt)

# Render chart with all interactive controls
chart = Chart(id="main", data=df_filtered, default_y="Sales", default_x="Month")
chart.update_figure()
chart.show_figure()

Date Grouping

# Add a date grouping selector (Daily/Weekly/Monthly/Quarterly/Yearly)
chart = Chart(id="ts", data=df, date_col="Order Date", default_y="Amount", default_x="DateGrouping")
chart.get_date_grouping(default="Monthly", default_min_num_periods=12)
chart.update_figure()
chart.show_figure()

Chart Class

The central component. Renders Streamlit controls and produces Plotly figures.

Chart(id, data, ...)

Initialize the chart with a DataFrame and display options. Automatically renders selector widgets for graph type, x, y, color, facets, size, bar mode, marginals, and height.

chart.update_figure(**kwargs)

Build the Plotly figure based on current widget selections. Handles date grouping, aggregation, date range filtering, and dispatches to the correct graph type.

chart.show_figure(use_container_width=True)

Display the figure in Streamlit via st.plotly_chart().

chart.get_date_grouping(default, ...)

Render a date grouping selector (Daily through Yearly) and optional min/max date range filter.

chart.show_data(raw_data, chart_data, map_data, ...)

Show data tables in expandable sections below the chart for debugging and exploration.

Chart.group_by_date(df, date_grouping, date_col, ...)

Static method. Aggregate a DataFrame by time period, summing an Amount column. Adds a DateGrouping label column.

Constructor Parameters

ParameterDescription
idUnique identifier for Streamlit widget keys
dataPolars or Pandas DataFrame to visualize
y_opts / x_optsColumn names for axis selectors (defaults to all columns)
color_optsColumns for color/facet/size selectors
default_*Default selections for each control (y, x, color, graph_type, facet_col, facet_row, size, barmode, bar_group, marginal, date_grouping, height, histogram_bins, orientation_h, sort_legend_by_value)
colormapsDict mapping column names to color dicts, e.g. {"Status": {"Active": "green"}}
date_colDatetime column for date grouping
map_hover_colsExtra columns for map hover tooltips

Filter Class

Build reusable, cacheable filter UIs that apply to Polars DataFrames or generate SQL.

Filter(id, filters=None, label_visibility="visible")

Initialize a filter group with a unique ID.

flt.selectbox(label, options, default, col_name, filter_type, bypass_option, ...)

Add a single-select filter. Supports comparison operators: eq, gte, lte, gt, lt. The bypass_option acts as an "All" selection that skips filtering.

flt.multiselect(label, options, default, col_name, ...)

Add a multi-select filter. Rows are kept where the column value is in the selected list.

flt.filter_sql(where_or_and="WHERE", prefix="")

Generate a SQL WHERE clause from active selections.

filter_data(df, flt, names=None, return_size_too=False)

Apply filter selections to a Polars DataFrame. Cached by Streamlit for performance.

combine_filters(filter1, filter2)

Merge two Filter objects, preferring non-empty values from filter1.

Graphs Module

Low-level Plotly figure factories with opinionated defaults.

graphs.graph(df, graph_type="bar", ...)

Create bar, line, or scatter figures. Supports grouped+stacked bars, auto-aggregation, legend sorting by value, color maps, and category ordering.

graphs.donut(df, values, names, ...)

Create donut/pie charts with percentage + value labels and optional faceting.

graphs.map(df, size_col, color_col, map_theme, ...)

Create scatter mapbox figures from lat/lon data with size and color encoding.

graphs.sankey(df, node1, node2, node0="Total", cmap=None)

Create 3-level Sankey diagrams from DataFrame columns.

graphs.sunburst(df, path, color, ...)

Create sunburst charts for hierarchical data exploration.

graphs.waterfall(sv1, n_top_features=9)

Create horizontal waterfall plots, designed for SHAP value visualization.

graphs.millify(n, precision=2)

Format numbers with human-readable suffixes (k, M, B, T).

Utilities

utils.pl2pd(df)

Convert a Polars DataFrame to Pandas, preserving date columns as datetime.date objects.
